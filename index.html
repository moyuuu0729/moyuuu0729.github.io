安裝與更新說明

  1. 確認瀏覽器已安裝 Tampermonkey（例如 Edge、Firefox、Kiwi 或 Safari 擴充功能）。
  2. 先點上方卡片的 「🚀 一鍵安裝 / 更新」；若瀏覽器自動跳出 Tampermonkey 畫面，直接點安裝即可。
  3. 若手機瀏覽器只打開純文字程式碼，請點 「📋 複製安裝網址」，進入 Tampermonkey → 實用工具 → 從網址安裝 貼上即可。
  4. 未來腳本更新時，到 Tampermonkey 面板點選檢查更新即可自動同步。
  1. 在 Chrome、Edge 或 Firefox 安裝 Tampermonkey 瀏覽器擴充套件。
  2. 直接點擊上方卡片的 「🚀 一鍵安裝 / 更新」 按鈕。
  3. 在跳出的 Tampermonkey 分頁中點擊「安裝」或「更新」，重新整理目標網站即可生效。
